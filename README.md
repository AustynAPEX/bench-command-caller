# Bench Command Caller

A phone page that watches the bar through the camera and calls IPF-style bench commands out loud:

- **Start** once the bar is still at lockout after the unrack
- **Press** a random 0.6–2.0 s after the bar stops on the chest (adjustable)
- **Rack** at lockout

Pressing before the call gives red lights and a buzzer. Each rep logs the pause length and the response time to the press call.

Open the GitHub Pages link on your phone, prop it side-on to the bench, tap a plate to lock tracking, then tap Arm.
